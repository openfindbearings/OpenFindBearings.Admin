# OpenFindBearings.Admin

统一管理后台，提供信息管理、审核、用户权限、审计与系统配置。所有数据操作通过项目 API 代理，不直连业务数据库。

## 技术栈

- ASP.NET Core MVC（.NET 10.0）
- Bootstrap 5 + jQuery
- JWT Bearer 认证（通过 Identity OAuth）
- 无自有数据库：业务数据经 API、身份与权限经 Identity

## 核心功能

- **信息管理**：品牌、轴承类型、轴承、商家、替代关系的 CRUD 与软删除恢复
- **审核中心**：信息纠错、入驻申请、证照材料、商品上架、寻货管理、成交回执、意见反馈
- **用户与权限**：用户列表、角色管理、权限清单（由 API 托管）
- **审计日志**：聚合展示 API 与 Identity 两端审计记录
- **系统配置**：站点设置、价格显示、限流与可信度阈值等运行时配置，勋章管理为其页签
- **仪表盘**：关键业务指标概览
